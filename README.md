# الشايب بالركن — الإصدار 2.2

موقع لعبة الشايب بالركن (Kings in the Corner) باللغة العربية، متوافق مع الجوال بالطول والعرض.

## الجولات المحددة
قبل بدء اللعب اختر ١، ٣، ٥، ٧، ١٠ جولات أو عددًا مخصصًا بين ١ و٣٠ (الافتراضي ٥). يظهر عداد الجولات أثناء اللعب، وبعد الجولة الأخيرة تنتهي المباراة تلقائيًا وتعرض ترتيب جميع اللاعبين بحسب مجموع النقاط الأقل. عند تعادل لاعبين أو أكثر بالمجموع الأقل يظهر التعادل. بعد الانتهاء يظهر زر «مباراة جديدة» الذي يبدأ من الجولة الأولى مع تصفير النقاط.

## التشغيل
افتح [اللعبة](./index.html) في GitHub Pages. تعمل لعبة فردية ضد الكمبيوتر أو جماعية على الجهاز نفسه. نمط الغرف عبر Firebase ما زال تجريبيًا؛ المزامنة الآمنة بين أجهزة مختلفة ليست مفعّلة بعد.

> المستودع المخصص للعبة: https://github.com/drburghash-sys/shayeb- .

لتفعيل رابط الموقع، اختر Settings → Pages → Deploy from a branch → main → / (root) ثم Save.
